# Ultra-Normal builds philosophical software for heroes of daily life.

These skills share one design principle: **the AI refuses to do the cognitive work for you.** They are instruments, not assistants. They make you a sharper thinker, not a faster consumer.

Use them yourself. Teach them to students. Install them in agents. Fork them freely. Attribution is the only ask.

### The library

- **[scalarview](https://github.com/justinneuman-coder/scalarview)** — think at the right altitude. Place any idea on a seven-level scale, from evidence to universal stakes.
- **[consultantmode-skills](https://github.com/justinneuman-coder/consultantmode-skills)** — twelve specialist modes that turn any agent into a structured business advisor.
- **[red-pencil-editor-skills](https://github.com/justinneuman-coder/red-pencil-editor-skills)** — substantive feedback on argument and style. Never a ghostwriter.
- **[unicornkick-skills](https://github.com/justinneuman-coder/unicornkick-skills)** — two coaches that refuse to do the work. The Writer never writes a sentence; the Ultra never fakes a mile.
- **[ai-distillery-skill](https://github.com/justinneuman-coder/ai-distillery-skill)** — teach an agent how *you* think. A portable profile distilled from your own work.

*Skills work with Claude, Claude Code, Cursor, Codex, Gemini CLI, and any agent that accepts a system prompt.*
